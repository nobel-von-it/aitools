# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для текущей ветки `main` и последней опубликованной версии `0.1.x`.

## Как сообщить об уязвимости

Не открывайте публичный issue с деталями уязвимости. Используйте приватный канал:

- GitHub Security Advisories в разделе `Security` репозитория;
- если приватный канал недоступен, свяжитесь с сопровождающим напрямую и дождитесь подтверждения.

В сообщении укажите:

- версию или коммит;
- операционную систему и способ запуска;
- минимальный сценарий воспроизведения;
- ожидаемое и фактическое поведение;
- оценку влияния.

## Модель угроз

`aitools` разбирает недоверенные документы и предоставляет доступ к файлам через MCP. Основные риски:

- обход ограничения путей в MCP-инструментах;
- чтение файлов вне каталога проекта через симлинки или `..`;
- обход проверки через base64-инструменты;
- расширение области доступа через изменение конфигурации или launcher'а;
- выполнение внешних программ через OCR-бэкенды.

## Что уже реализовано

- Каноникализация путей и проверка вхождения в `root` или активный грант.
- Запрет на грант всего `grant_base` и предков `root`.
- Гранты хранятся отдельно для каждого проекта в `<root>/.aitools/grants.json`.
- `request_access` рассчитан на подтверждение пользователем через `permissions` клиента.
- В песочнице отключены base64-инструменты (`--no-inline`).
- Launcher `scripts/aitools-mcp-sandbox.sh` ограничивает процесс сервера через `bwrap`.
- Журнал обращений и грантов пишется в `<root>/.aitools/audit.log`.
- Внешние OCR-бэкенды не исполняют содержимое документа, а только передают изображение известному бинарнику.

## Что не является гарантией

Песочница ограничивает процесс MCP-сервера, но не агента и не клиент. Если у агента есть доступ к `shell` с правами пользователя, он может читать файлы напрямую, минуя MCP. Для полной изоляции запускайте клиент в контейнере или под отдельным пользователем.

Tesseract и другие внешние программы запускаются с правами процесса. Устанавливайте только доверенные версии и не добавляйте в `PATH` подконтрольные недоверенному источнику бинарники.
